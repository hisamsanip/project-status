HOW TO USE
1. In Microsoft To Do, create a list called "Seremban Sentral - MCA Documentation".
2. Copy every line under LIST 1, paste into "Add a task", and confirm adding them as separate tasks.
3. Create a second list "Seremban Sentral - Ground Works" and do the same with LIST 2.
4. Set due dates and assign people in each task (shared lists only).
