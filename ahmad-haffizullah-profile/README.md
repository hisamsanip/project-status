## Before going live
In `index.html`, replace every `https://YOUR-SITE-URL/` (4 places, near the top) with the real address, for example `https://yourname.github.io/profile/`.

## Publish free with GitHub Pages (works from a phone browser)
1. Sign in at github.com. Tap **+** → **New repository**, name it `profile`, set it to **Public**, tick **Add a README file**, then tap **Create repository**.
2. In the repository, tap **Add file** → **Upload files** → **choose your files**. Select `index.html` and `og-image.jpg`, then tap **Commit changes**.
3. Go to **Settings** → **Pages**. Under **Branch**, pick `main` and `/ (root)`, then tap **Save**.
4. Wait 1–2 minutes. The site will be at `https://YOUR-USERNAME.github.io/profile/`.
5. Open `index.html` in the repository, tap the pencil icon, replace the four `https://YOUR-SITE-URL/` placeholders with that address, and tap **Commit changes**.

## Add it to LinkedIn
- **Featured:** Profile → **Add section** → **Recommended** → **Add featured** → **+** → **Add a link** → paste the URL → check the title → **Save**.
- **Contact info:** Profile → pencil on the intro card → **Contact info** → **Add website** → paste the URL, set the type to **Portfolio** → **Save**.
- **About:** Profile → pencil on **About** → add a closing line such as "Full profile and career: [URL]" → **Save**.
- **Refresh the preview:** open linkedin.com/post-inspector, paste the URL and tap **Inspect**. Do this again after any change to the title, description or image.
